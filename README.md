# 🚀 KWS Feed

Um protótipo de feed social construído com **React + Vite**, desenvolvido como parte dos estudos com a [Rocketseat](https://rocketseat.com.br). O projeto simula a estrutura de uma rede social com publicações, comentários e interação com os usuários.

---

## 🛠️ Tecnologias

- [React](https://reactjs.org)
- [Vite](https://vitejs.dev)
- [CSS Modules](https://github.com/css-modules/css-modules)
- [Phosphor Icons](https://phosphoricons.com)

---

## ✨ Funcionalidades

- Visualização de posts com avatar, nome e horário
- Comentários em cada post
- Ações de curtir e deletar comentário
- Estilização moderna com CSS Modules

---

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/kws-feed.git

# Acesse a pasta do projeto
cd kws-feed

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
